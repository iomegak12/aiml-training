Create src\northwind_loans\features.py with a Scikit-Learn transformer policy features (base estimator and mixin) - it must be STATELESS i.e. fit returns self, nothing is learnt from the data - accept pandas data frame return a pandas data frame with original columns plus the new ones, implement get feature names out and support set output to transform to pandas.

use the following guides and configuration specific CREDIT_POLICY - New Columns to be introduced accordingly.

- monthly_income        = annual_income / 12
- dti                   = monthly_existing_emi / monthly_income              (debt-to-income)
- credit_band           = "<600", "600-649", "650-699", "700-749", "750+" from credit_score
- foir_limit            = foir_by_credit_band[credit_band] + salaried_foir_bonus if employment_type == "Salaried"
- affordable_emi        = max(monthly_income * foir_limit - monthly_existing_emi, 0)
- annuity_factor        = (1 - (1 + r) ** -n) / r, where r = rate_card_pct[loan_purpose] / 1200 and
                          n = requested_tenure_months   (present value of 1 rupee of EMI per month)
- emi_capacity_amount   = affordable_emi * annuity_factor
- policy_cap            = income_multiple_cap[loan_purpose] * annual_income
- affordable_amount     = min(emi_capacity_amount, policy_cap, absolute_cap_income_multiple * annual_income)
- credit_haircut        = credit_haircut.get(credit_band, 1.0)
- policy_amount         = affordable_amount * credit_haircut
